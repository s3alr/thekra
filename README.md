# حصن المسلم | أذكار الصباح والمساء

موقع ثابت لأذكار الصباح والمساء الصحيحة بمصادرها.

## التشغيل محلياً
افتح `index.html` مباشرة في المتصفح.

## النشر عبر GitHub Pages
الموقع موقع ثابت (HTML/CSS/JS) ولا يحتاج بناء. يُنشر من فرع `main` مباشرة.

## المصادر
- صحيح البخاري ومسلم
- سنن أبي داود والترمذي والنسائي وابن ماجه
- مسند أحمد
- حصن المسلم بتحقيقات الألباني
